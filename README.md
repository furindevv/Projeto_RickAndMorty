# Multiverso Rick and Morty

Site estático (HTML + CSS + JavaScript puros) que consome a [Rick and Morty API](https://rickandmortyapi.com/) com `fetch` e cria os cards dos personagens dinamicamente via DOM.

- Busca por nome, filtro por status, paginação e favoritos (localStorage)
- Abrir: dê dois cliques em `index.html` (requer internet) ou publique no GitHub Pages
